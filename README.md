# devlog

Graphics programming devlog by OSANNnn, published at **https://osannnn.github.io/devlog/**.

The code it talks about lives in [gfx-lab](https://github.com/OSANNnn/gfx-lab).

## How it's built

A plain Jekyll site, built automatically by GitHub Pages on every push to `main`.

- `_posts/`: one Markdown file per post, named `YYYY-MM-DD-title.md`
- `_layouts/`: the page and post templates
- `assets/css/style.css`: the styles, matching [the portfolio](https://osannnn.github.io/)
